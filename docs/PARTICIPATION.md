# 参加型フル管理・ポップアウト・カスタムテーマ

## 方針

ユーザー提供の「参加型管理.zip」（Sanka Queue Manager 1.3.1）の参加型管理を本体として維持し、CastPanelの受信・保存・OBS・更新基盤へ接続しています。元の画面とカード編集は `vendor/sanka/`、統合ホストは `src/main/sanka.ts` です。別プロセスや別アプリを起動する方式ではありません。

## 開き方

「参加型」→「フル管理を開く」で、元の参加者一覧と「連携・設定」「参加管理」「OBS見た目」「カード」を開きます。「最前面ミニ表示」は小型・常時最前面で操作できます。メイン画面の参加型操作と参加者データを共有します。

- コメント／ポイント／両方の受付、YouTubeとTwitchの混在、Twitch認証とEventSub、参加条件・定員・再参加待ち時間・ブラックリスト・履歴を保持。
- 同時プレイ人数・連続回数・一括加算・交代・上限者削除・最大30操作取り消しを保持。
- 通知音、ユーザー設定可能なグローバルホットキー、最前面・ミニ表示、初回ガイドの再表示を保持。
- 6スタイル（リスト／カード／チップ／1行バー／スポットライト／リッチカード）、15テーマ、配置・フォント・透過・アクセント・登場／退場・出番の強調を保持。
- 元の9カードデザイン、背景・アイコン・フレーム・名前・回数の編集、ドラッグ配置、画像取込み、デザインファイルの入出力を保持。
- OBS効果音のプリセット・音声ファイル取込み、ドラッグによるブラウザソース追加、専用URL、操作ドックを保持。

Twitchの権限による参加制限は認証済みTwitchチャットの情報を使用します。YouTubeメンバーの判定は元のツールと同様に対象外です。Twitchの認証・ポイント交換・プロフィール画像の実受信には本人のログインと実配信での確認が必要です。

## 保存・同期

参加型の全設定・参加者・履歴・カスタムカードは `electron-store` 内の `studio.fullParticipation` に保存し、既存の参加型データから初回移行します。メイン画面用の `studio.participation` は同じエンジンの表示・操作用データとして同期します。別ウィンドウで行った変更もOBSとメイン画面に反映します。

画像・音声はユーザーデータ内の `sanka-assets/` に保存します。通常バックアップは設定・デザイン定義を含みますが、素材ファイル自体を含みません。別PCへはカードの書き出し／読込み、または素材フォルダーの移行を使用してください。

認証トークンはバックアップ・OBS・メイン画面の公開データに含めません。OS暗号化を利用できる場合にのみ専用設定へ保存し、利用できない環境ではセッション中だけ保持します。暗号化された認証情報はバックアップ復元の対象外です。復元後の受付と配信接続は停止します。

## OBS

- 参加型専用のURLはフル管理画面からコピーしてください。パスは `/sanka/overlay` です。
- 通常の `/overlay` と `?view=queue` も同じ参加型オーバーレイを埋め込みます。位置・大きさは従来のOBS配置画面で調整します。フォント・倍率・内部スタイルは参加型フル管理のOBS見た目で指定します。
- 操作ドックのURLには今回の起動用トークンをフラグメントで付けます。共有せず、再起動後は再コピーしてください。読み取り用WebSocketからの無認証操作は拒否します。
- ドラッグ追加用HTMLは起動時に現在のポートへ更新します。
- 効果音を有効にするブラウザソースは1つだけにしてください。全表示と専用表示の両方で有効にすると音が重なります。
- LANリモートビューは従来の簡易参加待ち表示です。フルカード・素材・効果音はローカルOBS用URLで使用してください。

## 別ウィンドウ

コメント、参加型、投票、ストック、曲・時刻、演出、電子名簿、OBS配置、テーマ編集、ログ解析を別ウィンドウで開けます。各画面の「別ウィンドウ」から開き、既に開いていればその窓へ移動します。最前面にも固定できます。

切り離したコメント画面では読み上げを重複実行しません。データと操作はメインプロセスを共有します。別ウィンドウの×はその窓だけを閉じ、メイン画面の×は全ウィンドウ・接続・サーバーを終了します。

## ユーザーテーマ

右上の「テーマ編集」または参加型フル管理の「テーマを自由に編集」から開きます。

1. 新規作成または15プリセットを下地として選択。
2. 背景・パネル・文字・補助文字・アクセント・枠線の色、角丸、枠の太さ、OBS背景の透過、影、フォントを編集。
3. 保存し、アプリ／OBS／参加型へ個別適用。
4. 複製・削除・JSONファイルの書き出し／読込みで共有。

最大30個を保存できます。テーマの設定と選択はバックアップ対象です。任意スクリプトや外部通信を含むCSSを実行する方式ではなく、編集可能なスタイル値として保存します。カード個々の素材とレイアウトは、参加型のカードデザイナーでさらに編集できます。

## 検証

`npm test` は参加条件・回数・取り消し・キーの同一性・カード定義・テーマ形式を検証します。Electronのスモークテストでは、実際のカード画面、画像取込み、OBSリッチカード、OBSプレビュー、ミニ表示、演出の切り離し操作、テーマ編集・同期、バックアップ復元、全窓の終了を確認します。

Twitch認証／実ポイント交換、外部音声機器、macOS／Linux、署名済み配布更新は実環境での検証が必要です。配布先はCastPanelの `electron-builder.yml` を使い、元の参加型ツールのReleaseへは接続しません。

取り消し用のスナップショットは元のツールと同様に起動中だけ保持し、再起動・バックアップ復元時にリセットします。メイン画面へは取り消し可能件数だけを渡し、大きな取り消しデータをコメントごとに転送しません。

OBSの全表示は `/overlay`、コメント専用は `/overlay?view=comments` です。専用URLでは他の機能は表示しません。OBS設定の「表示されないときの復旧」はコメントの時間消去を止め、参加型を受付停止中も表示する設定に戻します。読み取り用HTTPスナップショットも配信し、WebSocketが利用できない環境ではHTTP取得へ切り替えます。
