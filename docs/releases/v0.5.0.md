# CastPanel 0.5.0

複数サービスのコメント確認、参加型管理、OBS表示をまとめたデスクトップアプリです。ワンコメ経由でのコメント取得は行いません。

## 主な機能

- YouTube LiveのAPIキー不要のDOM取得、TwitchのIRC取得、接続枠ごとの読み上げ・名簿・ログ・OBS出力の切り替え。
- コメントの検索・固定・ストック・NGフィルター、初見／再訪表示、リスナー名簿とバックアップ。
- 参加型の受付・待機列・回数上限・交代・履歴・取り消し、管理用の別ウィンドウとミニ表示。
- OBS向けのコメント・参加者・投票・セットリスト表示、配置編集、テーマとカスタマイズ。
- Web Speechおよび外部音声エンジン向けアダプター、枠ごとの音声設定。
- 新しいアプリアイコンとGitHub Pagesの配布サイト。
- GitHub Releasesを使用する更新確認・ダウンロード・再起動適用。

## 導入

Windowsでは `CastPanel-0.5.0-win-x64.exe` を使用してください。OBSのブラウザソースURLはアプリ内に表示されるURLをコピーします。全表示は `/overlay`、コメントのみは `/overlay?view=comments` です。ポート番号は実際のアプリ表示に合わせてください。

## 現時点の制限

- 開発段階のリリースです。ワンコメとの完全互換・全機能の網羅を保証するものではありません。詳細はリポジトリの `docs/FEATURES.md` を参照してください。
- ツイキャスは試験実装です。配信サービスのページ構造・認証条件の変更により取得できなくなる場合があります。
- 外部TTS、外部連携、各OSの実機動作は利用環境での確認が必要です。VOICEPEAKは未実装です。
- 署名を設定せずに生成したWindows版は未署名です。macOS版の一般配布と自動更新には署名・公証の準備が必要です。
- 自動更新は正式リリースと更新メタデータの公開後に利用できます。旧版に正しい配布先が設定されていない場合、最初は手動インストールが必要です。

設定や名簿のバックアップを取ってから更新してください。
