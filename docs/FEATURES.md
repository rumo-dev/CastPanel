# OneComme機能対応表

照合日: 2026-10-27。公式の[機能一覧](https://onecomme.com/docs/feature/)、[メイン画面](https://onecomme.com/docs/settings/main/)、[対応サイト](https://onecomme.com/docs/feature/supported-sites/)を基準に、無料版・PRO機能の両方を追跡します。

**この表は全項目の実装完了を意味しません。** 「実装」はCastPanel独自仕様でコードとUIが存在する状態です。外部製品・配信サイトでの実受信確認は別です。わんコメのソース、素材、有料テンプレートは流用していません。

## 検証

- `npm test`: ドメイン処理、ログ、バックアップ、HTTP/WS認証・公開データのテスト。
- `npm run build`: 型チェックと本番ビルド。
- `node_modules\.bin\electron.cmd scripts/smoke.mjs`: 一時データで起動し、参加登録・投票・ストック・ログ・復元・終了を通す。`.smoke-data/ui.png`に画面を保存。
- ログインCookie・トークン・外部サービスでのコメント送信を必要とする確認は自動テストに含めない。

## 完全互換に向けた残作業

外部サービスアダプター、Twitch OAuth/EventSub、画像／バッジ、複合演出、複数質問の同時受付、テンプレート／プラグインSDK互換、Streamlabsとゆかりねっと連携が主な残作業です。音声エンジンは実製品との再生確認を別途必要とします。未実装・未検証を「網羅済み」と扱わず、この表で追跡します。
